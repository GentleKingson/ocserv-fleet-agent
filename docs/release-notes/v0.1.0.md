# ocfleet v0.1.0 Release Notes

## Summary

`v0.1.0` is the read-only MVP hardening release. It is intended for controlled evaluation of the controller registry, agent identity, fixed read-only RPCs, audit logging, and local troubleshooting workflow.

## Features

- `ocfleet` controller CLI backed by private SQLite state.
- `ocfleet-agent` node agent with explicit controller and peer EndpointID allowlists.
- Fixed read-only RPC methods: `node.ping`, `node.info`, `probe.controller.ping`, `probe.peer.echo`, and `probe.path.echo`.
- Controller audit table and agent JSONL audit log.
- Durable agent audit fallback spool with replay and metrics.
- `ocfleet doctor` human and JSON diagnostics.
- Release artifact checksum generation with `SHA256SUMS`.

## Install

Follow [`docs/install.md`](../install.md). The short form is:

```bash
./scripts/build-release.sh v0.1.0
./scripts/verify-checksums.sh dist/v0.1.0/SHA256SUMS
OS="$(uname -s | tr '[:upper:]' '[:lower:]')"
ARCH="$(uname -m)"
case "$ARCH" in arm64) ARCH="aarch64";; amd64) ARCH="x86_64";; esac
sudo install -m 0755 "dist/v0.1.0/ocfleet-v0.1.0-$OS-$ARCH" /usr/local/bin/ocfleet
sudo install -m 0755 "dist/v0.1.0/ocfleet-agent-v0.1.0-$OS-$ARCH" /usr/local/bin/ocfleet-agent
```

## Upgrade

Back up controller state and SecretKeys first:

```bash
sudo install -d -m 0700 /var/backups/ocfleet
sudo cp -a /var/lib/ocfleet-controller/controller.sqlite /var/backups/ocfleet/controller.sqlite.$(date -u +%Y%m%dT%H%M%SZ)
sudo cp -a /var/lib/ocfleet-controller/controller.secret /var/backups/ocfleet/controller.secret.$(date -u +%Y%m%dT%H%M%SZ)
sudo cp -a /var/lib/ocfleet-agent/iroh.secret /var/backups/ocfleet/agent.$(hostname).iroh.secret.$(date -u +%Y%m%dT%H%M%SZ)
```

Install the new binaries, restart agents, then run:

```bash
ocfleet --database /var/lib/ocfleet-controller/controller.sqlite --secret-key /var/lib/ocfleet-controller/controller.secret doctor
systemctl restart ocfleet-agent
systemctl status ocfleet-agent --no-pager
```

## Known Limitations

- No relay, mesh, route discovery, enrollment token, TOFU, or automatic node registration.
- Production transport uses private iroh defaults with relay and address lookup disabled. Controller-to-agent RPCs require reachable endpoint addressing supplied by the underlying deployment environment; the CLI intentionally does not accept host, port, or arbitrary address flags in this release.
- No raw ocserv, shell, file-read, `systemctl`, `occtl`, or `journalctl` adapter exists.
- Schema version is `1`; future migrations must keep `ocfleet doctor` green before rollout.
