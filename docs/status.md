# Project Status

This page reflects the current source tree. It is not a production-complete
claim, and planned items are not available unless marked implemented.

## Security And Contract Baseline

| Contract | Current source-of-truth state |
| --- | --- |
| Controller schema | SQLite schema version `8`, migrations `1` through `8`: core registry/audit, enrollment, endpoint trust, observability, strict constraints, retention indexes, health policy, and alert webhooks. |
| Generic allowed RPC methods | `node.ping`, `node.info`, `probe.controller.ping`, `ocserv.service.summary`, `ocserv.version`, `ocserv.sessions.summary`, `ocserv.cert.expiry`, `ocserv.config.fingerprint`. Authorization also admits controller-only `probe.path.echo` and peer-only `probe.peer.echo`; neither is a generic caller capability. |
| Known but not allowed | `ocserv.service.status`, `ocserv.status`, `ocserv.reload`, `ocserv.restart`, `ocserv.config.apply`, `ocserv.config.rollback`, `ocserv.session.disconnect`, `ocserv.users.list`, `ocserv.users.get`, `ocserv.logs.recent`, `ocserv.cert.status`, `ocserv.config.summary`. |
| API | Fourteen declared `GET` paths only. Non-loopback startup requires a private bearer token file and a TLS-terminating deployment boundary; the API itself does not terminate TLS. |
| Alert delivery | Scheduler evaluation only upserts local alert events. JSONL/webhook delivery is an explicit CLI action and never runs from the API/dashboard. |
| Controlled writes | Feature-gated DTO/config validation only. Default build and feature build contain no live dispatch; session disconnect has no safe selector and is rejected by the scaffold. |

| Feature | Current status | Main CLI | Main limits |
| --- | --- | --- | --- |
| Node registry | implemented | `ocfleet node add`, `ocfleet node list`, `ocfleet node enable`, `ocfleet node disable`, `ocfleet node remove`, `ocfleet node info` | Controller-local SQLite registry only; no discovery or automatic trust. Add/enable/disable/remove bind the resolved actor and commit registry/trust changes with their audit row in one transaction. Enable requires a clean bidirectional Active binding; removal revokes the unique Active trust before deleting the node. |
| Enrollment | implemented hardened slice | `ocfleet enroll token create`, `ocfleet enroll token revoke`, `ocfleet enroll request create`, `ocfleet enroll request reject`, `ocfleet enroll approve`, `ocfleet enroll claim` | Token/request transitions use actor-bearing atomic writers, stable optional request IDs, compare-and-set usage, closed terminal states, and low-sensitive audit. Approval atomically creates an operator-owned registry node and bound Active generation-1 trust. `claim` strictly repairs legacy approved-unbound rows. No identity is derived from hostname/labels and no automatic reconciliation exists. |
| Endpoint lifecycle | implemented | `ocfleet endpoint rotate`, `ocfleet endpoint revoke`, `ocfleet endpoint quarantine` | Closed controller-local lifecycle: Active may rotate/revoke/quarantine; Quarantined may rotate/revoke; Revoked is terminal; Rotated accepts only an exact linked retry. Exact no-ops do not bump generation or audit. Rotation moves the node pointer atomically, while revoke/quarantine disable the current node. No diagnostic shell or service control. |
| Trust diff | implemented | `ocfleet trust diff`, `ocfleet trust diff --endpoint <endpoint-id>`, `ocfleet trust diff --format json`, `ocfleet trust diff --strict` | Reports controller trust drift; does not auto-remediate or create trust. |
| Trust policy as code | implemented review-only slice | `ocfleet trust policy validate <file> --json`, `ocfleet trust policy diff <file> --json`, `ocfleet trust policy diff <file> --format markdown --output <path>` | TOML/YAML parity, explicit topology validation, deterministic advisory diff, JSON output, and bounded markdown review output are implemented. `validate` does not open SQLite; there is no apply command, agent contact, or automatic trust change. |
| Fixed RPC | implemented | `ocfleet ping`, `ocfleet node info`, `ocfleet probe ping`, `ocfleet probe path`, `ocfleet probe summary`, `ocfleet probe topology`, `ocfleet probe history`, `ocfleet probe observe` | Fixed methods and typed responses only; no raw command, file, log, or relay interface. Authorization requires an enabled registry node, matching node/EndpointID pointers, and exactly one Active trust binding. Missing, inactive, unbound, mismatched, or ambiguous state is rejected before key loading or network I/O, with complete scheduler source/target rechecks after concurrency waits. |
| ocserv readonly | implemented | `ocfleet ocserv status`, `ocfleet ocserv cert`, `ocfleet ocserv sessions summary` | Low-sensitive fixed RPCs only; controller cannot pass paths, commands, service units, or selectors. |
| Path probe | implemented | `ocfleet probe path <source-node-id> <target-node-id>`; `ocfleet schedule job add --kind path-probe --source-node-id <source> --target-node-id <target> --interval <duration>` | Explicit source/target pair only; no mesh enumeration, generic payloads, or multi-hop probing. |
| Scheduler | partially implemented / active implementation | `ocfleet schedule job add --name <name> --kind <kind> --interval <duration> [--selector role=<role>|node_id=<node-id>]`, `ocfleet schedule job list --json`, `ocfleet schedule job show <job-id> --json`, `ocfleet schedule job validate <job-id> --json`, `ocfleet schedule job enable`, `ocfleet schedule job disable`, `ocfleet schedule run --once [--job-id <job-id>] [--json]`, `ocfleet schedule run list --limit <n> --json`, `ocfleet schedule run show <run-id> --json`, `ocfleet schedule daemon`, `ocfleet schedule status --json` | CLI and SQLite job/run/observation path exists; fixed job kinds only. Job configuration and each run start, bounded outcome, and finish use actor-bearing `StoreWriter` transactions. Outcome audits pair with observations, and finish atomically advances the owning job clock; no transaction spans RPC work. Targeted run executes one explicitly named enabled job; Web/API is read-only and cannot trigger scheduler work. |
| Observations | partially implemented / active implementation | `ocfleet observation list --node <node-id> --method <method> --limit <n> --json`, `ocfleet observation show <observation-id> --json` | Bounded stored observation queries only; summaries are sanitized and no raw RPC response bodies are emitted. |
| Health | partially implemented / active implementation | `ocfleet health summary --json`, `ocfleet health node <node-id> --json`, `ocfleet health snapshot list --limit <n> --json`, `ocfleet health policy show`, `ocfleet health policy set` | Derived advisory state from controller SQLite observations; summary/node compute and upsert snapshots; snapshot list shows latest per-node rows only; no agent RPC is run by health commands. |
| Alerts | partially implemented / active implementation | `ocfleet alert list --state open|silenced|resolved --severity warning|critical --node <node-id> --json`, `ocfleet alert test jsonl_file:<path>`, `ocfleet alert hook add-webhook --name <name> --url https://... --hmac-secret-file <path> --host-allow <host>`, `ocfleet alert hook list --json`, `ocfleet alert hook test <hook-id> --dry-run`, `ocfleet alert deliver --hook jsonl_file:<path>`, `ocfleet alert deliver --hook webhook:<hook-id> --limit <n> --hmac-secret-file <path>`, `ocfleet alert silence <dedupe-key> --for-duration <duration> --reason <reason>`, `ocfleet alert resolve <dedupe-key> --reason <reason>` | JSONL file hooks and explicitly configured HTTPS webhook hooks only; webhooks require host allowlists, a fixed non-secret path catalog, public resolved IPs, HMAC secret files, bounded attempts/timeouts, and no redirect following; no shell, script, command, or automatic remediation hooks. |
| Retention | implemented hardened slice | `ocfleet retention show`, `ocfleet retention set <scope>`, `ocfleet retention explain --scope <scope> --json`, `ocfleet retention apply [--operation-id retention-<uuid>] --json` | Prunes only four fixed observation-history scopes. `explain` and `apply --dry-run` neither delete nor audit. Policy changes and each non-dry-run scope apply are actor-bound atomic writers; stable operation IDs provide exact replay across multi-scope partial progress. Protected tables are never targets. |
| Audit export | partially implemented / active implementation | `ocfleet audit export --from <rfc3339> --to <rfc3339> --format jsonl --output <path> [--redact none/default/strict] [--include-checksum] [--sign-with-key-file <path>] [--max-rows <n>]` | Bounded controller audit window only; writes private JSONL output and optional checksum/Ed25519 signature sidecars. |
| Governance foundation | partially implemented / active implementation | `ocfleet --actor <actor> ...`, `OCFLEET_ACTOR=<actor> ocfleet ...` | Unified actor resolver and fixed viewer/operator/security-admin policy vocabulary are implemented; local CLI does not enforce RBAC. API principals are viewer-only. Enrollment, retention, node/endpoint lifecycle, and scheduler configuration/run execution use actor-bearing `StoreWriter` boundaries; a static guard rejects direct production mutator bypasses. Health/alert/delivery and other paths remain to migrate, so full fail-closed writer migration is not complete. |
| Web/API | partially implemented / active implementation | `ocfleet-api --database controller.sqlite --read-only --listen 127.0.0.1:8080` | Experimental read-only `GET` observation surface only with `docs/api/openapi.yaml`; uses the API-specific `ApiReadStore` over SQLite read-only connections; non-loopback listeners require `--auth-token-file`; no API route triggers agent RPC, scheduler runs, alert mutations, retention changes, trust changes, or node registry changes. |
| Dashboard | partially implemented / active implementation | `GET /` from `ocfleet-api` | Static read-only dashboard for health, nodes, jobs, runs, observations, alerts, and a bounded audit export preview; sends CSP/referrer/content-type hardening headers; no non-GET fetch or control buttons. |
| Local ocserv collector | safety-constrained normalizer; no live discovery | `ocfleet-ocserv-collector --config <collector.toml> --output <path>`, `ocfleet-ocserv-collector --check --config <collector.toml>`, `ocfleet-ocserv-collector --print-example-config` | Local operator-managed reduced snapshot transform only; no service-manager/log/admin-tool passthrough, raw source capture, or controller-supplied path. It preserves producer `collected_at`, so timer runs cannot make static metadata fresh. This is not a completed live ocserv collector. |
| Controlled operations | planned / not implemented | Design only in `docs/controlled-write-operations.md`; draft DTOs are feature-gated and not wired to dispatch. | Default build remains read-only; no reload, restart, config apply/rollback, session disconnect, raw command, shell, script, raw file, or dashboard/API mutation route is implemented. |
